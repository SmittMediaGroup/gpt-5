# РЕЦЕПТЫ-КИНО — герой лендинга как рекламный ролик (разведка 03.10.2026)

Жанр-эталон, который показал владелец (4 рилса): первый экран лендинга — это
**фотореалистичный рекламный ролик**, который проигрывается ОДИН раз и замирает в идеальный
стоп-кадр; гигантский заголовок стоит ЗА предметом; поверх — тончайший hairline-интерфейс.
Здесь: полный пайплайн, раскадровки эталонов, готовые промты для наших 4 страниц,
разведка Scrolltide.co и авторов, что купить. Код — в `C:\smg\lendingi-vau\hero-kit\`.

---

## 1. Суть жанра — пять слагаемых

1. **Физическое событие с продуктом** (не «атмосферная петля»): зёрна взрываются, молоко
   вливается, шоколад льётся, попугай летит в камеру. Одно событие, 4–8 секунд, slow motion.
2. **Невидимое замирание**: ролик играет один раз и застывает в стоп-кадр; стык не виден,
   потому что **финальный кадр видео — это и есть герой-стилл страницы** (см. §3).
3. **Текст за предметом**: серифный/акцидентный заголовок во всю ширину, предмет его
   частично перекрывает → иллюзия глубины.
4. **Частицы орбитой**: после замирания зёрна/лепестки/стикеры остаются висеть вокруг
   предмета и медленно дрейфуют (это уже CSS, не видео).
5. **Киноплёнка поверх**: grain (зерно), scrim (затемняющий градиент под текст),
   bloom (мягкое свечение за предметом), rings (тонкие концентрические окружности),
   spot (пятно света) + hairline-UI (линии 1px, один залитый элемент на экран).

Пункты 3–5 делаются кодом (hero-kit), генерируется только 1 стилл + 1 видео.

## 3. Главный секрет: невидимый стык (замирание)

Три уровня надёжности, от лучшего к запасному:

**A. Стилл — первым, видео — К стиллу (рекомендую).**
1. Генерируем ГЕРОЙ-СТИЛЛ (идеальный кадр, где всё застыло) — это конечная точка.
2. Генерируем видео в модели с управлением кадрами (**Veo 3.1 Quality в Google Flow /
   Kling start+end frame / Higgsfield image2video с end frame**): *end frame = наш стилл*,
   start frame = «спокойное» состояние (или тот же стилл для идеальной петли).
   Урок Scrolltide (perfect-loop): «make the end frame the same image as the start frame…
   the loop is seamless by construction rather than by luck» — для нас то же, но стык
   не петли, а замирания: **последний кадр видео = постер страницы = фон после freeze**.
3. На `ended` видео само останавливается на последнем кадре; поверх мгновенно (120 мс
   fade) поднимается тот же стилл в полном качестве. Пиксели совпадают → стык невидим.

**B. Если модель не держит end frame точно** — финальный кадр ДОСТАЁМ ИЗ ВИДЕО и он
становится стиллом страницы:
```bash
# последний кадр видео → герой-стилл
ffmpeg -sseof -0.05 -i hero.mp4 -frames:v 1 -q:v 1 poster.png
# вырезка предмета для слоя «текст за предметом» (python -m pip install rembg)
rembg i poster.png cutout.png
```

**C. Канвас-страховка** (встроена в hero-kit): на `ended` кадр дорисовывается в canvas
`ctx.drawImage(video, 0, 0)` — защита от браузеров, сбрасывающих последний кадр.

**Чистка и сжатие** (ролик — самый тяжёлый ассет, держать < 3–5 МБ):
```bash
ffmpeg -i raw.mp4 -ss 0.4 -t 7.6 -an -vf "scale=1600:-2,fps=24" \
  -c:v libx264 -preset slow -crf 23 -pix_fmt yuv420p -movflags +faststart hero.mp4
# webm-вариант легче ~30%:
ffmpeg -i hero.mp4 -c:v libvpx-vp9 -b:v 0 -crf 34 -an hero.webm
# реверс (для сборки MELT-типа «куски собираются в креманку»):
ffmpeg -i vzryv.mp4 -vf reverse -an sborka.mp4
```

**Текст ЗА предметом** (без текста в генерации — наш запрет остаётся в силе):
слои `фон-стилл (z0) → <video> (z1) → ЗАГОЛОВОК (z2) → cutout предмета PNG (z3) →
частицы (z4) → scrim/bloom/rings/grain (z5) → hairline-UI (z6)`.
Пока видео играет, заголовок приглушён и с радиальной маской-дырой вокруг предмета;
после замирания cutout встаёт НАД заголовком → текст «уходит за предмет». Готово в
`hero-kit/src/VideoFreezeHero.tsx`.

**Обязательные атрибуты видео**: `autoPlay muted playsInline preload="auto"
poster={still}` и БЕЗ `loop`. `muted` обязателен для автоплея, `playsInline` — для iOS.
Отказ автоплея (данные-экономия, старые браузеры) → сразу показываем замороженную сцену.
`prefers-reduced-motion` → видео не грузим вообще.

## 4. Полный пайплайн (по шагам, = уроку Scrolltide «AI-generated video hero»)

1. **Референсы** на всю страницу (не только герой), держать под рукой весь билд.
2. **Стилл** в нужном соотношении (16:9 широкоэкранный, у нас + вертикальный 4:5 для
   телефона): «widescreen and a clear area where the headline will sit» — ОСТАВЛЯТЬ
   ПУСТУЮ ЗОНУ под заголовок и контраст в ней.
3. **Видео**: одно событие, сдержанная камера (статичный штатив или slow push),
   4–8 секунд. Veo 3.1 Quality (Flow) с frame control; у нас — Higgsfield
   (image2video с конечным кадром), 16 кредитов, максимум ОДНО видео на лендинг.
4. **Чистка**: убрать вотермарку (кроп 4–6 px), обрезать до события, сжать (см. §3),
   сделать постер.
5. **Хостинг**: класть рядом со страницей на demo-сервер (у Scrolltide — Cloudinary и
   передавать Клоду URL, не файл; нам хватает `/var/www/demo-smg/files/...`).
6. **Вёрстка**: «Hero first, and finished, before anything else exists» — герой доводится
   до идеала раньше остальных секций; дальше секция за секцией со своим референсом.
7. **Приёмка**: кадры Playwright 1440×900 и 390×844 в 3 моментах (до/во время/после
   замирания), замер `zamer.py`, вес первого экрана: видео НЕ входит в бюджет 1,5 МБ
   первого отрисованного кадра, потому что постер-стилл показывается мгновенно, а
   видео догружается (`preload="auto"` ставить только когда герой — главный ассет).

Бюджет Higgsfield на страницу: стилл 2–2,5 кр + видео 16 кр ≈ **18,5 кр** (потолок 40,
перед генерацией — `balance`, каждую генерацию — в ledger.json).

## 5. ГОТОВЫЕ ПРОМТЫ под наши 4 страницы

Формула видео-промта (Veo/Kling/Higgsfield): *Subject + Action + Scene + Camera + Style*
(+ Audio для Veo 3). Правила: одно событие; «slow motion», «locked-off tripod shot»;
тёмный/заливочный фон нашей палитры; БЕЗ текста, логотипов, рук, людей, интерфейсов;
финал — «settles into a perfectly still frame». Пояснения по-русски, промты — по-английски.

### 5.1 «Ноктюрн» — цветочная мастерская (пион + малина на тёмно-вишнёвом)

**Стилл (end frame):**
```
Ultra-realistic product photograph, a single lush blush-pink peony in full bloom
floating centered above a dark polished stone pedestal, fresh raspberries and loose
peony petals suspended motionless in the air around the flower like an orbit, fine
mist droplets frozen mid-air, deep dark cherry / black-burgundy background (#2A0A12),
dramatic soft spotlight from upper left, cinematic rim light on petal edges, shallow
depth of field, large empty area in the upper half for a headline, no text, no hands,
no people, 16:9, commercial food-and-flower advertising style, 8k detail
```
**Видео (к этому кадру):**
```
Slow-motion macro commercial shot, locked-off camera. A blush-pink peony bud rises
from a dark polished pedestal and blooms open; ripe raspberries and single petals
are tossed upward around it and decelerate; a silky swirl of dark cherry juice wraps
around the flower once; everything slows down and settles into a perfectly still
frame: the open peony centered, raspberries and petals hanging motionless in orbit
around it. Deep dark-burgundy background, single soft spotlight, fine floating dust,
photorealistic, cinematic, 8 seconds, no text, no hands.
```
Частицы-орбита в коде: лепестки + ягоды (2 PNG-вырезки из стилла через rembg).

### 5.2 «Корпоративное обучение ИИ» (жёлтый на графите, рой стикеров/букв)

**Стилл:**
```
Ultra-realistic studio photograph, a glossy graphite-black office desk object set —
a closed laptop standing upright like a monolith on a graphite pedestal — surrounded
by a swarm of bright yellow sticky notes and 3D letters frozen mid-air in a perfect
orbit around it, saturated yellow background field (#F5C400), hard studio light,
crisp shadows, clean empty band across the middle for a headline, no text on notes,
no logos, no people, 16:9, bold advertising still-life, hyperdetailed
```
**Видео:**
```
Commercial slow-motion shot, static camera. A graphite-black laptop stands closed on
a pedestal against a saturated yellow background; hundreds of blank yellow sticky
notes burst upward from the desk like a flock of birds, swirl around the laptop in
a vortex, then decelerate and lock into a clean circular orbit as the laptop lid
opens slightly emitting a warm glow; the scene settles into a perfectly still frame.
Hard studio lighting, crisp shadows, photorealistic, 8 seconds, no text, no people.
```
Смысловая привязка: рой стикеров = хаос ручных задач, после обучения они встают в
стройную орбиту. Слова-курсив по бокам (как у MELT) — «15 человек», «7 000 ₽/час».

### 5.3 «Внедрение ИИ» (оранжевый; детали процесса собираются в механизм в воздухе)

**Стилл:**
```
Ultra-realistic industrial advertising photograph, a precise brushed-steel and brass
mechanism (gears, shafts, small turbine) fully assembled and floating in mid-air
above a dark walnut podium, a few last screws and cogs hanging motionless around it
in orbit, saturated deep-orange background field (#E8541A), dramatic warm side light,
soft long shadows, clean empty area on the left third for a headline, no text,
no logos, no hands, 16:9, premium watch-commercial aesthetic, hyperdetailed macro
```
**Видео (генерировать как РАЗБОРКУ, проигрывать реверсом — приём MELT-Б):**
```
Slow-motion commercial shot, locked-off camera. A precise brushed-steel and brass
mechanism floating above a dark walnut podium explodes gently outward: gears, shafts
and screws drift apart in slow motion against a saturated deep-orange background,
each part rotating slowly, warm dramatic side light, fine dust sparkling.
Photorealistic, 8 seconds, no text, no hands.
```
`ffmpeg -vf reverse` → детали СЛЕТАЮТСЯ в механизм и замирают. Реверс-сборка надёжнее:
модели лучше «взрывают», чем «собирают».

### 5.4 «ИИ-сотрудники» (зелёный неон; бейдж падает в луч света, частицы собирают силуэт)

**Стилл:**
```
Ultra-realistic cinematic photograph, a matte-black employee ID badge on a woven
lanyard hanging perfectly still in a vertical shaft of bright neon-green light
(#00FF7F) inside a dark concrete server room, luminous green particles around the
badge forming a faint translucent human silhouette behind it, volumetric light,
haze, reflections on the floor, clean dark area on the right for a headline,
blank badge with no text and no photo, no people, no logos, 16:9, sci-fi
advertising key visual, hyperdetailed
```
**Видео:**
```
Cinematic slow-motion shot, static camera. In a dark concrete room a matte-black
employee ID badge on a lanyard drops from above into a vertical neon-green light
beam, decelerates and stops mid-air; thousands of luminous green particles rush in
from the darkness and assemble a faint translucent human silhouette standing behind
the badge; haze and volumetric light, the scene settles into a perfectly still
frame. Photorealistic, moody, 8 seconds, blank badge, no text, no people's faces.
```

**Общие стоп-слова для всех генераций**: text, letters, captions, watermark, logo,
UI, hands, fingers, extra objects, deformed product, camera shake, fast cuts.
Для телефона: либо вторая генерация 4:5/9:16, либо тот же ролик с `object-position`
на предмет (дешевле; герой `100svh`, предмет держать в центральной трети).

## 8. Что владельцу стоит купить / решить

1. **Scrolltide Monthly $29 за 1 месяц** — если хотим эталонные промты (Parrot + 9 других
   премиум-hero с исходным кодом). Не обязательно: hero-kit уже воспроизводит слои.
   Lifetime $239 — только если затянет; возвратов нет. Бесплатную регистрацию (4 шаблона)
   можно сделать и без решения — но нужна почта, поэтому оставляю владельцу.
2. **Veo 3.1 Quality (Google Flow, подписка Google AI Pro ~$20)** — единственный из
   доступных нам генераторов с точным управлением первым+последним кадром = идеальный
   невидимый стык. Без него работаем через Higgsfield end-frame + страховку B (ffmpeg
   кадр из видео) — тоже рабочо, уже заложено в рецепт.
3. **Решить: добавляем ли видео-героев в 3 готовых вау-лендинга** (obuchenie-ii /
   vnedrenie-ii / ii-sotrudniki) или сначала на одном (рекомендую ii-sotrudniki — сцена
   «бейдж в луче» самая дешёвая по риску: тёмный фон прощает артефакты). ~18,5 кредитов
   Higgsfield на страницу, перед стартом `balance` (порог 756 из ТЗ).
4. Cloudinary НЕ нужен — у нас свой demo-сервер.
