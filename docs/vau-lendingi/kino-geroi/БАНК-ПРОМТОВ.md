# Банк промтов жанра «продукт-событие-замирание» — вторая волна, 03.10.2026

Собрано из открытых библиотек (videogen.io/veo-3-prompts, Curious Refuge, Creatide,
aireiter, godofprompt, разбор рилсов эталона) + наш опыт. ВСЁ адаптировано под
железное правило владельца: **никакого чёрного/тёмного — яркие сплошные цветные поля**.

## 1. Формула (подтверждена всеми библиотеками)

**Subject + Action + Scene + Camera + Style (+ Audio для Veo со звуком)**

Рабочий каркас видео-промта под наш стык (start=end=стилл):

```
Slow-motion commercial shot, locked-off camera on a tripod.
[SUBJECT — один продукт] centered on a saturated solid [ЦВЕТ] background field.
[ACTION — одно физическое событие 3–6 c: взрыв/вливание/сборка/всплеск вокруг продукта].
Everything decelerates, [частицы] lock into a clean orbit around [продукт],
and the scene returns to the exact starting composition, settling into a perfectly
still frame identical to the first frame.
Bright high-key studio lighting, crisp shadows, photorealistic, 8k detail,
[N] seconds, no text, no letters, no logos, no hands, no people.
```

Правила, вытащенные из банков и эталонов:
- ОДНО событие на ролик, не цепочка (цепочку MELT мы не повторяем — дороже и дрейфует).
- Камера всегда «locked-off / static tripod» — любой панинг ломает совпадение кадров.
- Движение ЗАМКНУТОЕ: вылетело → вернулось/зависло; «returns to the exact starting
  composition» писать явно (Creatide: constrained path-finding вместо свободной
  экстраполяции).
- Контраст событий: «burst/explode outward», «pour from above», «assemble mid-air»,
  «splash crown», «swirl once around» — глаголы, которые модели отрабатывают лучше всего.
- Реверс-приём: «собирание» генерить как ВЗРЫВ и проигрывать задом наперёд
  (`ffmpeg -vf reverse`) — модели взрывают лучше, чем собирают.
- Текст НИКОГДА не в кадре (Curious Refuge: «Don't bake text into the frames.
  Composite it later»). Эталонные рилсы enky — с «текстом» в видео, поэтому там
  тарабарщина «Wixury fuving ice-cream»; у нас текст — живой HTML поверх.
- Стоп-слова всегда: text, letters, captions, watermark, logo, UI, hands, fingers,
  people, extra objects, deformed product, camera shake, fast cuts, dark background,
  black background.

## 2. Эталонные примеры рынка (дословно, из открытых библиотек)

Product hero (videogen.io):
```
Studio product hero shot of a matte black wireless earbud case rotating slowly on a
glossy dark surface, dramatic rim lighting, dust particles in the light beam
```
(нам: поверхность и фон менять на яркое поле, «glossy dark» → «glossy coloured»)

Food slow-motion (videogen.io):
```
Overhead slow-motion shot of honey drizzling onto a stack of golden pancakes,
steam rising, morning kitchen light
```

Ganache orbital (videogen.io):
```
Dark chocolate ganache drips slowly over a tall chocolate layer cake on a marble
pedestal, captured in a slow orbital shot with dramatic studio light
```
(orbital shot — НЕ для нашего стыка; берём только пластику события)

Nutella-взрыв (veo3promptwriter, пересказ — сайт недоступен напрямую):
деконструкция банки в контролируемом красивом взрыве — вихри шоколада, целые
фундучины, клубника и тосты летят в макро-деталях, slow motion. Это ровно пластика
COFFEE COLLISION.

Приём first/last для продукта (Curious Refuge, 8 ways): «use a tight close-up as
your first frame and a wide hero shot as your last frame» — вариант для второй
сцены-ролика (не для героя: герою нужен start=end).

## 3. Каркас стилл-промта (end frame = герой страницы)

```
Ultra-realistic advertising product photograph. [SUBJECT] centered [on/above]
[подиум/поверхность в цвет семьи], [частицы] suspended motionless in mid-air in a
clean elliptical orbit around it, saturated solid [ЦВЕТ #HEX] background field,
bright high-key studio lighting with crisp soft shadows, large clean empty band
across the [upper third / left third] for a headline, photorealistic, 8k detail,
16:9, no text, no logos, no hands, no people.
```

Детали из эталонов (мои глаза, кадры 694–697):
- Частицы в стоп-кадре стоят на ЧИТАЕМОЙ эллиптической орбите (у COFFEE COLLISION
  видна буквально пунктирная линия-эллипс) — слово «clean elliptical orbit» в промте
  даёт именно это.
- Продукт перекрывает заголовок НИЖНЕЙ третью букв — зона заголовка в стилле должна
  заходить ЗА продукт, поэтому «empty band across the upper third» + продукт по центру.
- После замирания по бокам появляются курсивные слова (HTML, приём MELT/Fluxora:
  «italic serif on the word doing the work»).

## 4. Чек-лист перед генерацией (90 секунд)

1. Поле — ЯРКОЕ сплошное, один цвет семьи, #HEX в промте. Чёрное/тёмное = в корзину.
2. Зона заголовка пустая и контрастная? (headline band)
3. Событие одно? Замкнутое? Камера locked?
4. Стоп-слова на месте? Текста в кадре нет?
5. start_image = end_image = одобренный стилл; sound 'off'; 5 с.
6. `balance` ≥ 665? Запись в ledger.json готова?
