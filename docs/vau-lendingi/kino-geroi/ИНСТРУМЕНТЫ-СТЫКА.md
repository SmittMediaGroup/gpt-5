## 2. Рынок вне Higgsfield (чтобы знать, НЕ покупать)

- **Veo 3.1 (Google Flow / Gemini API)**: «Frames to Video» — первый+последний кадр,
  «Ingredients to video» — референсы. В API $0.20–0.40/с без звука ($0.40–0.60 со
  звуком) — ролик 8 с ≈ $1.6–4.8. Подписка Google AI Pro $19.99/мес ≈ 90 генераций
  Veo 3.1 Fast или ~10 полного Veo 3.1 в месяц. Доступность — в основном США (нам
  неудобно). Вывод: не нужно — veo3_1_lite и kling3_0 с end frame есть в нашем Plus.
- **Kling AI (kling.ai напрямую)**: start/end frame живёт со versions 1.0–1.6 и
  вернулся в 3.0; отдельная модель **Kling O1** — специализированный first→last
  interpolator (есть на fal.ai). Через Higgsfield нам это уже оплачено планом.
- **Runway**: Gen-3 Alpha/Turbo умели First/Last/First+Last keyframes; **Gen-4 Turbo
  last frame НЕ держит** (только первый кадр). Для нашего приёма Runway сейчас хуже —
  пришлось бы жить на устаревшем Gen-3. Не нужен.
- Прочие обёртки (pollo.ai, wavespeed, dreamega, seaart…) — те же модели с наценкой.

## 3. Приёмы и код стыка (суммарно, вторая волна)

1. **Стык по построению**: start=end=стилл (Scrolltide perfect-loop: «seamless by
   construction rather than by luck»). У нас не петля, а замирание: видео играет
   один раз, `onended` остаётся на последнем кадре = стилле = постере.
2. **Дисциплина промта на возврат** (из разбора Creatide про бесшовные лупы):
   движение должно быть ЗАМКНУТЫМ (всплеск-возврат, раскрытие-остановка), камера
   locked; явно писать «returns to the exact starting composition and settles into
   a perfectly still frame»; НЕ брать одноходовые выходы (улетел и не вернулся).
   Диагностика: приложить последний кадр к первому ДО перегенерации — расхождения
   по framing/light/pose чинятся только перегенерацией, не полировкой.
3. **Кадры-якоря без motion blur** (урок 10 Scrolltide): старт/энд кадры должны быть
   резкими, иначе модель «закрепляет» смаз.
4. **Композит текста — всегда в HTML** (Curious Refuge: «Don't bake text into the
   frames. Composite it later») — совпадает с нашим железным запретом текста в
   генерации.
5. **Код замирания** — уже в hero-kit (`VideoFreezeHero.tsx`): `autoPlay muted
   playsInline preload="auto" poster={still}` без `loop`; на `ended` — canvas
   `drawImage(video,0,0)` + fade 120 мс на полный стилл; `prefers-reduced-motion` →
   видео не грузим. ffmpeg-чистка/реверс/постер — РЕЦЕПТЫ-КИНО §3.
6. **Сжатие**: ролик < 3–5 МБ, `-crf 23 -preset slow`, webm-вариант −30%;
   постер-стилл отдаём мгновенно, видео догружается.
7. Смежные рецепты с кодом (на развитие, не MVP): Codrops «Layered Zoom Scroll
   (ScrollSmoother)» 29.10.2025, «Cinematic 3D Scroll Experiences with GSAP» (19.11.2025,
   репо github.com/JosephASG/codrops-cinematic-scroll-animations), «3D Scroll-Driven
   Text Animations CSS+GSAP» (04.11.2025) — tympanus.net/codrops. Скролл-скраб:
   60–120 кадров WebP на canvas с прелоадом (уроки 8–10 Scrolltide).
