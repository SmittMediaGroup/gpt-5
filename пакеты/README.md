## Порядок перед публикацией
1. `python3 scripts/obhod_kataloga.py` — список демо с кодами в `data/katalog-demo.csv`.
2. Вписать витрины и демо с кодом 200 в `scripts/sobrat_pakety.py` (списки `VITRINY`, `DEMOS3`), затем запустить `python3 scripts/sobrat_pakety.py`.
3. `python3 scripts/proverka_ssylok.py` — должно быть «не 200: 0».
4. Закрыть все «[нужно от владельца]», убрать плашку и `noindex`, подключить отправку формы.
