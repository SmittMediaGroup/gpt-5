## 4. Что публикую и что нет

### 4.1. Порог n
- Публикую только клетки с **n ≥ 40** ответов системы. Если после брака у системы меньше 40, вся её колонка идёт как «n = __ < 40, не публикуется», без процентов.
- Каждая опубликованная доля — в формате `k/n, %, [ДИ]`. Процент без k/n не публикую.

### 4.2. «Значимая» разница: Ньюкомб + Холм
Слово «значимо» пишу, только если 95 % интервал Ньюкомба для разности Алиса − ChatGPT не содержит 0 **с поправкой Холма на 12 сравнений**.

Простыми словами: у меня 12 клиник, значит 12 проверок. Если каждую проверять при обычных 95 %, то даже при полном отсутствии различий шанс увидеть хотя бы одну «значимую» разницу доходит примерно до 46 % (1 − 0,95¹²). Поправка Холма делает требования строже, и строже всего к первой проверке:
1. Для каждой клиники считаю p-значение разности (z-тест двух долей, `ztest` из `raschet_barometra.py`).
2. Сортирую клиники от меньшего p к большему.
3. Первая должна пройти порог p < 0,05/12 = **0,0042** (это то же самое, что интервал Ньюкомба на уровне 99,58 %, z = **2,865**, не содержит 0). Вторая — p < 0,05/11 = 0,0045 (z = 2,838), третья — 0,05/10 = 0,005 (z = 2,807) и так далее до двенадцатой: 0,05 (z = 1,96).
4. Как только клиника порог не прошла, она и все следующие — «не значимо».

Коротко для поста: **«с поправкой на 12 сравнений порог для самой сильной разницы — p < 0,0042»**.

Полная лестница: шаг 1 — 0,00417 (z 2,865); 2 — 0,00455 (2,838); 3 — 0,00500 (2,807); 4 — 0,00556 (2,773); 5 — 0,00625 (2,734); 6 — 0,00714 (2,690); 7 — 0,00833 (2,638); 8 — 0,0100 (2,576); 9 — 0,0125 (2,498); 10 — 0,0167 (2,394); 11 — 0,0250 (2,241); 12 — 0,0500 (1,960).

Число сравнений всегда 12, даже если какая-то строка не публикуется из-за n < 40: список зафиксирован заранее.

### 4.3. Нули
Ноль публикую только как **«0 из n, верхняя граница __ %»** (95 % Уилсона). При n = 40 это 8,8 %, при n = 48 — 7,4 %, при n = 60 — 6,0 %. С поправкой на повторы (DEFF 2) граница вдвое хуже: при n = 48 это 13,8 %. Формулировки «нейросеть не знает клинику» и «клиники нет в Алисе» не использую.

### 4.4. Брендовые ответы
- Брендовые ответы (B01–B04) в долю и в таблицу не идут.
- Если система сказала о конкретной клинике неправду (не тот адрес, выдуманные цены, чужие отзывы, «работает круглосуточно», когда это не так), **без согласия клиники это не публикую**, ни с названием, ни в узнаваемом виде. Медицина — чувствительная тема: неверный адрес или цена от нейросети могут выглядеть как обвинение клиники. Такие находки я отдаю самой клинике, если она попросит, а в выпуск пишу только агрегат: «в __ из 12 брендовых ответов Алисы есть хотя бы одна фактическая ошибка» (если n позволяет, иначе без цифр).
- Тональность публикую, только если у клиники ≥ 10 ответов с упоминанием (правило шаблона).

### 4.5. Реклама медицинских услуг (осторожная оговорка)
Это не юридическая консультация и я это не проверял поиском в рамках этой задачи. У такой рекламы по Закону № 38-ФЗ «О рекламе» есть особые требования (в частности, предупреждение о противопоказаниях и необходимости консультации специалиста). Поэтому:

### 5.4. Порядок расчёта (из корня репозитория `/home/user/gpt-5`)
1. **Каждая строка таблицы:** Уилсон для обеих долей и Ньюкомб для разности.
   ```

   ```
   Для Perplexity (одна доля): `python3 -c "import sys; sys.path.insert(0,'metodika'); from tri_cifry import wilson; p,l,h=wilson(K,N); print(f'{K}/{N}, {p:.0%}, [{l:.0%}; {h:.0%}]')"`, подставив K и N.
2. **Холм на 12 сравнений.** Сложить k/n в `barometr/data-2/doli.csv` с колонками `brand,k_alice,n_alice,k_chatgpt,n_chatgpt` (12 строк) и запустить:
   ```
   python3 - <<'EOF'
   import csv, sys
   from statistics import NormalDist
   sys.path.insert(0, 'metodika'); sys.path.insert(0, 'barometr')
   from tri_cifry import newcombe
   from raschet_barometra import ztest
   rows = list(csv.DictReader(open('barometr/data-2/doli.csv', encoding='utf-8')))
   m = 12
   res = sorted((ztest(int(r['k_alice']), int(r['n_alice']), int(r['k_chatgpt']), int(r['n_chatgpt']))[1], r['brand'],
                 int(r['k_alice']), int(r['n_alice']), int(r['k_chatgpt']), int(r['n_chatgpt'])) for r in rows)
   stop = False
   for i, (p, b, k1, n1, k2, n2) in enumerate(res):

   EOF
   ```
