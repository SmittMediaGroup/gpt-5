Дополнительно указывается, у скольких брендов из k разница значима. Шумовой порог считается перемешиванием меток систем: если индекс ниже порога, пишу «не отличается от шума».
- **43% против 26% (Бобкэт Центр)** при n = 30 ответов на систему не значимо (p = 0,18). При n = 60 это граница (p = 0,056). Значимо начиная примерно с 62 независимых ответов. Если ответы — повторы (2 на промпт), нужно около 93.

- **Юридический риск.** Некорректное сравнение запрещено ст. 14.3 закона 135-ФЗ, ответственность — ст. 14.33 КоАП. Рекомендация: называть компании только с их согласия или обезличивать, подавать выпуск как исследование. Нужно уточнить у юриста про маркировку рекламы.

**Что осталось:** подставить реальное n (число промптов × повторов), режим ChatGPT и данные Perplexity. **Без n выпуск №1 публиковать нельзя.**

- Код проходит `py_compile`, разбор ответов проверен на заглушках. **Живых вызовов не было: ключей нет.**

**Что выяснилось (по файлам официальных SDK и proto):**
- **GigaChat.** Серверная история появляется, только если передать `storage` или `X-Session-ID`. «Чистый» запрос — без них. Отдельного флага памяти в API нет.
- **YandexGPT.** Completion не хранит состояние, `x-data-logging-enabled` отвечает за логирование, а не за память.
- **OpenAI Responses.** `store` по умолчанию true; `previous_response_id` и `conversation` подмешивают историю.
- **Perplexity Search.** Запросы без состояния.
- **Yandex Search API.** Есть генеративный ответ `/v2/gen/search`, но поля региона в нём нет.
- **«Поиск с Алисой».** Публичного API нет. Описан ручной протокол: гостевой профиль, `lr=63`. Playwright дан как схема, он выключен по умолчанию, потому что автоматизация может нарушать соглашение Яндекса.

**Расхождение, которое надо решить.** `audit-v2.md` исключает браузерную автоматизацию и снимает Алису только вручную. Здесь есть опциональная схема Playwright. Я рекомендую ручной протокол.

**Что осталось:**
- Дословный пункт соглашения Яндекса об автоматических запросах.
- Поведение памяти Алисы у гостя.
- Совпадает ли ответ `/v2/gen/search` с ответом Алисы. Это нужно проверить одним живым сравнением.
