# Движение: кривые, тайминги, пружины

Справочник, чтобы не подбирать числа заново. Стек: Framer Motion (`motion` / `motion.dev`)
+ Lenis. Документация по переходам: https://motion.dev/docs/react-transitions

## Что по умолчанию

| Параметр | Значение по умолчанию | Ссылка |
|---|---|---|
| `duration` у tween | 0,3 с (0,8 с, если задано несколько ключевых кадров) | motion.dev/docs/react-transitions |
| `bounce` у spring | 0,25 | там же |
| `damping` | 10 | там же |
| `mass` | 1 | там же |
| `repeatType` | `loop` | там же |
| `delay` | 0 | там же |

Умолчание 0,3 с — короткое. Для «дорогого» ощущения входы делаются длиннее, выходы короче.

## Наши рабочие значения

| Что | Длительность | Кривая | Почему так |
|---|---|---|---|
| появление блока при прокрутке | 0,6–0,8 с | `[0.22, 1, 0.36, 1]` (easeOutExpo-подобная) | долгий «выезд» и мягкая остановка — это и читается как дорого |
| уход блока | 0,25–0,35 с | `[0.4, 0, 1, 1]` | уход должен быть быстрее входа, иначе страница «липнет» |
| наведение на кнопку | 0,15–0,2 с | `easeOut` | отклик должен быть почти мгновенным |
| нажатие | 0,1 с, `scale: 0.98` | `easeOut` | |
| разворот карточки / смена секции | 0,5 с | `[0.65, 0, 0.35, 1]` | симметричная, когда начало и конец одинаково важны |
| «дыхание» фона, медленный зум | 8–20 с | `linear`, `repeatType: 'mirror'` | бесконечное движение не должно иметь кривой, иначе заметны толчки |
| пружина для перетаскивания и курсора | `{ type: 'spring', stiffness: 300, damping: 30, mass: 0.6 }` | — | физика вместо кривой там, где движение прерывают |
| мягкая пружина для параллакса | `{ stiffness: 60, damping: 20 }` через `useSpring` | — | сглаживает рывки скролла, не добавляя задержки |

Задержки в серии (stagger): 0,06–0,10 с между элементами. Больше 0,12 с — список
начинает «ползти», меньше 0,04 с — эффекта не видно.

### Сверка с отраслевым справочником

Таблицы длительностей из скилла LottieFiles `motion-design` (MIT,
https://github.com/LottieFiles/motion-design-skill) — совпадают с нашими
значениями и уточняют их:

| Элемент | Длительность |
|---|---|
| подсказка (tooltip) | 80–120 мс |
| нажатие кнопки, тоггл | 120–180 мс |
| смена иконки | 150–250 мс |
| вход/выход карточки | 200–350 мс |
| модальное окно | 300–400 мс |
| переход страницы | 400–600 мс |
| «драматичный» reveal | 600–1200 мс |

Характер по типу бренда: Playful 150–300 мс с перелётом 10–20%;
**Premium 350–600 мс, перелёт 0%**; Corporate 200–400 мс, перелёт 0–3%;
Energetic 100–250 мс, перелёт 15–30%. Нам нужен Premium — то есть долго и
**без перелёта**. Бюджет stagger: micro <200 мс, standard <400, dramatic <600.
Правило дистанции: за базу берут 100 px; 200 px — ×1,3 длительности, 400 px — ×1,6.

## Кривые в CSS-записи

```css
--ease-out-expo: cubic-bezier(0.16, 1, 0.3, 1);     /* выезд и остановка */
--ease-out-quint: cubic-bezier(0.22, 1, 0.36, 1);   /* наш основной вход */
--ease-in-out-quart: cubic-bezier(0.76, 0, 0.24, 1);/* смена секций */
--ease-out-back: cubic-bezier(0.34, 1.56, 0.64, 1); /* лёгкий перелёт, только для мелочей */
```

`ease-out-back` — только для иконок и бейджей. На крупных блоках перелёт выглядит
игрушечно, а это ровно то, чего мы избегаем в «ярком, но дорогом».

## Прокрутка

Дефолты Lenis по README (https://github.com/darkroomengineering/lenis):
`lerp` 0.1, `duration` 1.2 с, `smoothWheel` true, `syncTouch` **false**,
`respectReducedMotion` **true**. Lenis не перехватывает прокрутку, а «оборачивает»
нативную, поэтому `position: sticky` и якоря продолжают работать.

| Параметр Lenis | Значение | Комментарий |
|---|---|---|
| `duration` | 1,0–1,2 | больше 1,5 — страница «плывёт», пользователь теряет связь с колесом |
| `lerp` | 0,1–0,15 | выше — заметная задержка |
| `smoothWheel` | `true` | |
| `syncTouch` | `false` (дефолт) | на телефоне инерция и так нативная; включать не надо |

Связка с Motion — через `frame.update()`, с GSAP — через `gsap.ticker.add()`;
при внешнем цикле ставить `options={{ autoRaf: false }}`
(https://github.com/darkroomengineering/lenis/tree/main/packages/react).

Цена приёма: Nielsen Norman Group, «Scrolljacking 101» — изменение темпа прокрутки
бьёт по управляемости, большинство участников испытывали дезориентацию, часть
принимала поведение за баг (https://www.nngroup.com/articles/scrolljacking-101/).
Поэтому Lenis держим мягким и не трогаем направление прокрутки.

Длина скраб-секции (sticky-блок, внутри которого крутится анимация): 150–250% высоты
экрана. Короче 150vh — эффект мелькает; длиннее 300vh — пользователь думает, что
страница сломалась.

## Пороги, которые нельзя нарушать

1. **60 кадров в секунду** — анимируем только `transform` и `opacity`. Любая анимация
   `width`, `height`, `top`, `left`, `box-shadow`, `filter` на крупном блоке роняет кадры.
2. **Не больше 2 одновременных анимаций в поле зрения.** Третья перестаёт читаться
   и превращается в шум.
3. **Первый экран не анимируется дольше 1,2 с суммарно.** Дальше посетитель
   воспринимает это как «сайт тормозит», а не как «красиво».
4. **`prefers-reduced-motion: reduce`** — гасим параллакс, скраб, автозапуск видео
   и бесконечные петли; оставляем смену непрозрачности не длиннее 0,2 с.
   Справка: https://developer.mozilla.org/en-US/docs/Web/CSS/@media/prefers-reduced-motion
   В Framer Motion есть готовый хук `useReducedMotion`:
   https://motion.dev/docs/react-use-reduced-motion
