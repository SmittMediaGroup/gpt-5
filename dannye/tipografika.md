# Типографика: пары, размеры, правила

## Кегль героя относительно экрана

Главная цифра жанра. Измеряется зондом (`bigType.vw` в `dannye/zond-sayta.cjs`) —
самый крупный кегль на первом экране в процентах ширины окна.

Замер 02.10.2026 по 34 живым сайтам (окно 1440×900, метод — самый крупный
текстовый узел на первом экране; составные заголовки из вложенных span метод
может занижать):

| Сайт | Крупнейший кегль | % ширины |
|---|---|---|
| tonyschocolonely.com | 176 px | **12,2%** |
| lusion.co | 115 px | 8,0% |
| farmgirlflowers.com / drinkolipop.com | 90 px | 6,3% |
| buildinamsterdam.com | 86 px | 6,0% |
| dixonbaxi.com / hellomonday.com | 80–81 px | 5,6% |
| graza.co / oddbox.co.uk | 72 px | 5,0% |
| mailchimp.com | 64 px | 4,4% |
| stripe.com / koto.studio | 48 px | 3,3% |
| jacquemus.com | 18 px | 1,3% |

Вторая выборка — награждённые цветные сайты из галереи, кегль снят прямо
с `h1` по вычисленным стилям (метод точнее):

| Сайт | Кегль H1 | % ширины | Гарнитура |
|---|---|---|---|
| Gelato La Boca | 176,7 px | **12,3%** | The Bystander Collection |
| Gut Heladería | 156 px | **10,8%** | Rubik 500 |
| Oh les fleurs ! | 130 px | **9,0%** | gulax |

Вывод по двум выборкам: обычные брендовые сайты живут в **3–6% ширины**, а
награждённые цветные — в **9–12%**. Это и есть зазор между «нормальным сайтом»
и «вау». Ниже 4% эффекта не будет; выше 12% помещается только одно короткое слово.

| Величина | Что это даёт |
|---|---|
| < 4% ширины | обычный сайт, «вау» не будет |
| 5–6% | безопасная норма для длинной русской фразы |
| **9–12%** | жанр награждённых цветных лендингов; на 1440 px это 130–175 px |
| > 13% | помещается только одно слово из 5–7 букв |

Русский текст в среднем на 10–15% длиннее английского, поэтому верхнюю границу
берём осторожно: английское `BLOOM` на 16% встанет, «НОКТЮРН» — уже нет.

На телефоне (наше правило, не замер): 9–12 vw, то есть 35–47 px при ширине 390.
Меньше 8 vw — экран выглядит как мобильная версия обычного сайта.

Запись в Tailwind: `text-[clamp(2.25rem,7vw,8rem)]` — нижняя граница для узких
экранов, верхняя чтобы на 27″ заголовок не разрывал макет. Для одного короткого
слова можно `clamp(2.5rem,11vw,12rem)`.

## Пары гарнитур

Правило: **одна характерная + одна нейтральная**. Две характерные спорят, две
нейтральные дают скуку.

| Заголовок | Текст | Характер | Где брать |
|---|---|---|---|
| Unbounded | Golos Text | геометрический гротеск + нейтральный, обе с кириллицей | `@fontsource-variable/unbounded`, `@fontsource-variable/golos-text` — уже стоят в «Ноктюрне» |
| Playfair Display | Raleway | антиква с контрастом + лёгкий гротеск; «мягкое и дорогое» | `@fontsource-variable/playfair-display` |
| Bitter / Literata | Inter | серьёзный, редакционный | Google Fonts |
| Involve / Onest | Onest | современный русский гротеск | Google Fonts, есть кириллица |
| Cormorant | Manrope | высокий контраст, «бутик» | Google Fonts |

Вывод: почти вся «дорогая» латиница закрыта лицензией и без кириллицы. Для русских
проектов берём бесплатные переменные шрифты с кириллицей (Unbounded, Golos Text,
Onest, Involve, Bitter, Literata, Playfair Display, Cormorant, Prata) — список
замен в таблице выше.

Для кириллицы проверять два знака: «ж» и «ю» — на них ломается половина
латинских гарнитур. И цифры: нужны `lining-nums` для цен.

Подключение: только переменные шрифты (`@fontsource-variable/...`), `font-display: swap`,
`preload` для одного файла заголовочной гарнитуры. Остальные начертания — лениво.

## Шкала размеров

Шаг 1,25 (мажорная терция) для спокойных страниц, 1,333–1,5 — для «вау»:
контраст между заголовком и текстом должен быть заметным.

| Роль | Десктоп | Телефон |
|---|---|---|
| герой | clamp(2.5rem, 11vw, 12rem) | 10–14 vw |
| заголовок секции | clamp(2rem, 4.5vw, 4.5rem) | 7–9 vw |
| подзаголовок | 1.25–1.5rem | 1.1rem |
| основной текст | 1rem–1.125rem | 1rem |
| подпись | 0.8125rem | 0.8125rem |

Межстрочный у героя — 0,95–1,05 (заголовок должен быть «плотным блоком»),
у текста — 1,5–1,65.

Межбуквенный у крупного заголовка — отрицательный: −0,02…−0,04em. Без этого
крупный кегль выглядит рыхлым. У мелких подписей-капслоков — наоборот, +0,08…+0,14em.

## Длина строки

45–75 знаков. На широких экранах ограничивать `max-w-[65ch]`, иначе текст
растягивается на всю ширину и читается тяжело.

## Контраст

Минимум по WCAG 2.2: 4,5:1 для обычного текста, 3:1 для крупного (от 24 px, или
от 18,7 px жирного). Проверять **для текста на цветной плашке** — именно там
обычно и проваливаются: белый на насыщенном коралле часто даёт 2,8:1.
Справка: https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html

Правило для цветных плашек: если белый текст не проходит — не затемняем плашку,
а ставим тёмный текст из той же палитры (тёмный оттенок акцента).
