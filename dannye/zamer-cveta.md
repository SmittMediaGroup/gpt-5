# Как мы меряем «ярко или полумрак» числом

Спор «красиво / не красиво» бесконечен. Поэтому первый экран меряется, а не обсуждается.
Два инструмента лежат рядом.

## `zamer.py` — цвет и свет по снимку

```bash
python dannye/zamer.py kadr.png                 # один файл
python dannye/zamer.py papka/                   # вся папка
CVET_OUT=itog.json python dannye/zamer.py ...   # куда писать JSON
```

Нужны `numpy` и `Pillow`. Выдаёт по каждому кадру:

| Показатель | Что это | Норма для героя лендинга |
|---|---|---|
| `colorfulness` | метрика красочности Hasler & Süsstrunk, 2003 (DOI 10.1117/12.477378) | **не ниже 40** |
| `L_sredn` | средняя светлота L* (CIE) | 45–70 |
| `yarkiy_cvet_%` | доля пикселей с S≥0,40 и V≥0,50 — настоящий яркий цвет | **не меньше 12%** |
| `nasyshchennye_%` | доля пикселей с S≥0,35 по HSV | справочно |
| `neytralnye_%` | доля пикселей с S<0,12 — воздух, белое, серое | 25–55% |
| `temnye_V<0.25_%` | доля тёмных пикселей | не больше 25% |
| `dominanty` | 6 доминирующих цветов: hex, доля площади, H/S/V | — |

Важная оговорка про `nasyshchennye_%`: в HSV насыщенность считается как
(max−min)/max, поэтому тёмно-коричневый пиксель формально «насыщенный». Для
тёмных страниц этот показатель врёт — смотреть надо `yarkiy_cvet_%`, где к
насыщенности добавлено условие по яркости.

Пороги категорий красочности из той же работы: <15 «не красочно», 15–33 «чуть»,
33–45 «умеренно», 45–59 «средне», 59–82 «довольно», 82–109 «очень», >109 «предельно».

## `zond-sayta.cjs` — разбор чужого сайта

```bash
NODE_PATH=C:/smg/data/higgsfield/node_modules node dannye/zond-sayta.cjs urls.txt shots out.json
```

Открывает каждый адрес в Chrome 1440×900, ждёт загрузку и 3,5 с анимаций, снимает
первый экран (и отдельно 390×844 для телефона) и собирает по странице:

* статус ответа, конечный URL, заголовок — так проверяется, что сайт жив;
* суммарный вес ответов и разбивка по типам, число запросов;
* `bodyBg`, `bodyColor`, топ-10 фоновых цветов по площади и топ-8 цветов текста — **настоящие hex, а не на глаз**;
* гарнитуры: `font-family` у body, h1, h2 и список всех применённых семейств;
* `bigType` — самый крупный кегль на первом экране в px и **в процентах ширины окна** (ключевая цифра жанра);
* число `video`, `canvas` (и сколько из них WebGL), `img`, `svg`;
* обнаруженные библиотеки по адресам запросов и по глобальным объектам: gsap, three, lenis, locomotive, framer-motion, lottie, rive, barba, swiper, embla и платформы (Next, Nuxt, Shopify, Webflow, WordPress).

Оговорка про вес: считается сумма `content-length` всех ответов. Сайты со стримящимся
видео показывают завышенное число — это оценка «сколько утекло за первые секунды»,
а не вес страницы.

## Порядок работы

1. Сняли эталон и свой экран одним и тем же зондом.
2. Прогнали оба через `zamer.py`.
3. Сравнили три числа: красочность, долю яркого цвета, долю тёмного.
4. Разница в этих числах и есть то, что владелец называет «у них ярко, у нас полумрак».
