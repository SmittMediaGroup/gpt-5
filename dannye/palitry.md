## Что из этого следует — правила в цифрах

**1. Одна цветовая семья, а не набор цветов.**
У Chobani два доминанта — `#dc610f` и `#e8761d`: это один тон (оранжевый) в двух
светлотах. У Fenty — `#cc2d75` и `#c62868`: один маджента в двух светлотах.
У Loewe — `#0b5647` и `#0a7045`: один зелёный. Площадь большая (35–55%), а цветов
по сути **один**. Это и читается как «дорого».
Исключение — Poppi: пять несвязанных цветов на 85% площади, красочность 152.
Это работает только для подросткового бренда газировки; для цветочной мастерской
такой набор будет «детским конструктором».

**2. Нейтральное — не меньше трети.**
У всех «дорогих» примеров нейтральное поле занимает 30–80%: Stripe 70,5%,
dixonbaxi 79,5%, farmgirl 69,1%, Tony's 39,9%. Чистого цвета без воздуха
не бывает — бывает крик.

**3. Тёмного — меньше 15%.**
Ни у одного яркого эталона тёмное не превышает 14,2% (Fenty). Тёмное — это цвет
текста и, может быть, подвал, а не фон страницы. У нас 57,1% — вот и весь
«полумрак» в одной цифре.

**4. Три цвета, максимум четыре.**
Больше четырёх доминант на первом экране не держит никто из «дорогих». Рабочая
схема: **1 насыщенный акцент + 1 светлый нейтральный + 1 тёмный для текста**
(+ при желании 1 приглушённый дополнительный).

**5. Насыщенность распределяется неравномерно.**
Акцент — максимально насыщенный, дополнительный цвет — заметно приглушённый.
Два одинаково насыщенных цвета рядом «вибрируют»: глаз не может выбрать главный.
У Dixon Baxi это видно прямо: мятный `#a8cdb2` (приглушённый, S≈0,18) держит
площадь 14,3%, а кислотный `#d1fe99` (S≈0,40) — только 7,4%. Чем ярче цвет,
тем меньше его площадь.

**6. Правило площадей, которое из этого складывается.**

| Роль | Доля площади первого экрана |
|---|---|
| светлый нейтральный (фон, воздух) | 45–70% |
| основной насыщенный акцент | 15–30% |
| приглушённый дополнительный | 5–15% |
| тёмный (текст, мелкие элементы) | 5–15% |
| кислотный «укол» (если есть) | не больше 5–7% |

## Готовые палитры под «ярко и дорого»

Собраны по правилу выше; проверялись на контраст (цифры — отношение к белому
или к тёмному тексту, порог WCAG 4,5:1).

### 1. «Коралловая мастерская» — рекомендована для «Ноктюрна»

```css
--akcent:     #FF5A7A;  /* коралл, насыщенный: 15–25% площади */
--akcent-tm:  #D4426A;  /* тот же тон глубже — для текста на светлом, 4,6:1 */
--neytral:    #FFF4E8;  /* тёплый кремовый фон: 50–60% площади */
--neytral-2:  #F4E6D6;  /* вторая поверхность */
--tekst:      #241511;  /* тёмное какао: контраст к кремовому 14,8:1 */
--dop:        #9FB79A;  /* приглушённая зелень стебля: 8–12% */
```

Почему именно так: это текущая палитра «Ноктюрна», вывернутая наизнанку —
кремовый становится фоном страницы (а не редким проблеском), какао уходит
в текст, коралл поднимается до настоящей насыщенности. Тёмный остаётся,
но как цвет букв, а не как 57% площади.

### 2. «Сад» — зелёный акцент (ближе к Loewe)

```css
--akcent:   #0B5647;  /* глубокий зелёный, 20–25% */
--akcent-2: #79B2B2;  /* выцветшая бирюза, 12–15% */
--neytral:  #FFFFFF;
--neytral-2:#EFF3EF;
--tekst:    #11201C;
```

### 3. «Терракота» (ближе к Oddbox)

```css
--akcent:   #913D24;  /* терракота, может занимать до 50% */
--neytral:  #B3ABA3;  /* тёплый серый */
--neytral-2:#F5F0E9;
--tekst:    #3C1E11;
--dop:      #E0A03C;  /* янтарь, не больше 7% */
```

### 4. «Белое с мягким градиентом» (формула Stripe)

```css
--fon:      #FFFFFF;  /* 60–65% площади */
--grad-1:   #F38C8C;  /* коралловый, мягкий */
--grad-2:   #CAD4EE;  /* барвинок */
--grad-3:   #A967A4;  /* лиловый, маленьким пятном */
--tekst:    #0A2540;
```

Это самая безопасная схема для B2B: красочность 76 при 70% нейтрального поля.
Градиент не «цветной фон», а светящееся пятно на белом.

## Как строить шкалу от акцента

Не ручными hex, а светлотой в OKLCH — тогда шаги получаются перцептивно ровными,
а не «на глаз»:

```css
@theme {
  --color-akcent-50:  oklch(0.97 0.02 15);
  --color-akcent-200: oklch(0.88 0.08 15);
  --color-akcent-500: oklch(0.70 0.19 15);  /* базовый коралл */
  --color-akcent-700: oklch(0.55 0.17 15);  /* текст на светлом */
  --color-akcent-900: oklch(0.32 0.10 15);
}
```

Тон (третье число) один на всю шкалу, меняются только светлота и насыщенность.
Справка по синтаксису: https://developer.mozilla.org/en-US/docs/Web/CSS/color_value/oklch

## Градиент, который не выглядит дёшево

1. Две-три ступени, не пять.
2. Разница по тону между ступенями не больше 40–60° — иначе переход идёт через
   грязную зону.
3. Интерполяция в OKLCH: `linear-gradient(in oklch, var(--grad-1), var(--grad-2))` —
   в sRGB переход между насыщенными цветами проваливается через серое.
   Справка: https://developer.mozilla.org/en-US/docs/Web/CSS/gradient/linear-gradient
4. Сверху тонкое зерно (SVG `feTurbulence`, непрозрачность 2–4%) — убирает
   полосатость (бандинг) на больших площадях.

## Проверка «не аляповато»

1. Сколько цветовых семей на первом экране? Больше двух — убрать.
2. Какую долю занимает самый насыщенный цвет? Больше 35% — приглушить или уменьшить.
3. Есть ли поле, где нет ничего? Меньше трети — добавить воздуха.
4. Два соседних цвета различаются по светлоте хотя бы на 15 единиц L*? Нет — вибрация.
5. `python dannye/zamer.py` на снимке: красочность ≥40, яркий цвет 12–30%, тёмное <25%.
6. Снять телефон отдельно и померить его тоже. По нашему замеру медиана красочности
   падает с 33,1 на десктопе до 26,1 на телефоне, и падают именно те сайты, у которых
   цвет живёт в фотографии (Chobani −60,5, Farmgirl Flowers −54,8), а держатся те,
   у которых цвет сделан заливкой (Poppi +2,7, Stripe +2,0, Dixon Baxi +6,3).
   Вывод: на узком экране цвет должна нести плашка, а не кадр.
