## Модели и их параметры (сверено с `models_explore` 02.10.2026)

| Модель | Тип | Что умеет | Параметры |
|---|---|---|---|
| `recraft_v4_1` | изображение | **единственная модель с жёсткой палитрой**: `colors` до 10 цветов `#RRGGBB` + `background_color` | `resolution` 1k/2k, `model_type` standard/vector/utility/utility_vector |
| `nano_banana_pro` | изображение | качество, текст, работа по референсам (`image_references`) | `resolution` 1k/2k/4k |
| `nano_banana_2` | изображение | быстрее, есть `is_inpaint` + роль `mask` | `resolution` 1k/2k/4k |
| `seedream_v5_pro` | изображение | правка по инструкции, `remove_bg`, `is_inpaint` | `resolution` 1k/1.5k/2k |
| `soul_location` | изображение | только окружение/фон, без параметров; есть 21:9 и 9:21 | — |
| `z_image` | изображение | самая быстрая и дешёвая, стилизованная | — |
| `flux_2` | изображение | точное следование промту | `resolution` 1k/2k, `variant` pro/flex/max |
| `minimax_h3` | видео | **start_image + end_image** (ключевые кадры), 2K | `duration` 4–15 с, `batch_size` 1–4 |
| `kling3_0_turbo` | видео | дешёвая анимация одного кадра | `resolution` 720p/1080p, `duration` 3–15 с |
| `kling2_6` | видео | физика, движение | `duration` 5 или 10 с, `sound` |
| `seedance_2_0` | видео | предметные ролики, мульти-SKU, 4k | `mode` std/fast, `bitrate_mode`, `generate_audio` |

Проверить состав и параметры: `models_explore` с `action:"list"` или `action:"get"`.

## Расход кредитов — факт по нашему реестру

Из `C:\smg\data\higgsfield\assets\higgsfield\ledger.json` (план Plus, 1200 кредитов в месяц;
на 01.10.2026 остаток 1128,5):

| Операция | Кредитов |
|---|---|
| `nano_banana_pro`, картинка 1 шт. | 2 |
| `recraft_v4_1 vector 1k`, 1 шт. | 2,5 |
| `kling3_0`, видео 8 с 16:9 | 16 |

Порядок работы: сначала картинка (2–2,5 кредита), и только одобренный кадр превращаем
в видео (16). Неодобренные идеи в видео не уходят. Реестр заполняется до генерации.

## Правило, которое дороже всех промтов

Скриншоты наших сайтов и интерфейсов в генерацию НЕ отправляются — модель искажает текст.
ИИ делает только обёртку: фон, предмет, петлю. Интерфейс кладётся поверх в вёрстке.
