## 1. Дизайн выборки

### 1.1. Единица наблюдения и поверхности

Одна строка данных — один ответ одной поверхности на один промпт в один момент (повтор r). Поверхности считаю **раздельно**, среднее по ним не вывожу (см. 05-metriki.md, п. 5.3).

| № | Поверхность | Что это на самом деле | Метрика |
|---|---|---|---|
| G1 | YandexGPT (API Yandex AI Studio) | Модель отвечает «по памяти». Есть ли в API инструмент веб-поиска и сколько он стоит — нет данных | Доля упоминаний в ответах |
| G2 | Yandex Search API, генеративный ответ (GenSearch) | Официальный ближайший аналог «Поиска с Алисой»: ответ нейросети по результатам поиска Яндекса. **Это не тот же продукт**, что «Поиск с Алисой» в интерфейсе | Доля упоминаний + доля цитирования домена |
| G3 | GigaChat API | Ответ модели. Есть ли веб-поиск в API — нет данных | Доля упоминаний |
| G4 | OpenAI API + web search tool | Ответ модели с веб-поиском. **Это не тот же продукт**, что ChatGPT в браузере | Доля упоминаний + доля цитирования домена |

Почему S1 нельзя смешивать с G1–G4. В выдаче бренд «присутствует», если есть ссылка на его сайт или страницу о нём. В генеративном ответе он присутствует, только если модель назвала его в тексте. Это разные события с разными базовыми частотами. Их сумма или среднее ничего не значит. Генеративные ответы Perplexity (Sonar) в базовый пакет не включаю, потому что они платные. ### 1.2. Корреляция: повторы и перефразы

Промпты вкладываются друг в друга так: **интент** («где сделать МРТ в Иркутске») → **перефразы** (2 формулировки) → **повторы** (2 прогона каждой). Ответы внутри одного интента коррелированы. Эффект дизайна для такой двухуровневой схемы **[расчёт]**:

DEFF = 1 + (r − 1)·ρ₁ + r·(q − 1)·ρ₂,

где r — повторы, q — перефразы, ρ₁ — корреляция повторов одного промпта, ρ₂ — корреляция разных перефраз одного интента. ρ₁ = 0,5 я беру из 05-metriki.md. ρ₂ = 0–0,3 — **[гипотеза]**, опубликованных оценок нет.

Почему 2 перефразы × 2 повтора, а не 10 повторов одного промпта. При ICC 0,5 «10 × один промпт» даёт DEFF 5,5. Разных интентов должно быть как можно больше, а повторы нужны только для измерения повторяемости (05-metriki.md, табл. 3).

### 1.4. Как составлять набор промптов

1. **Пишу с позиции клиента, а не бренда.** Источники: Вордстат, подсказки поиска, вопросы из звонков и чатов заказчика, отзывы. Бренд, его адрес и уникальные приметы в небрендовые промпты не вставляю.
2. **Типы интентов и доли в наборе** (для 30 интентов; для 60 пропорции те же):

| Тип | Доля | Интентов из 30 | Пример (стоматология, Иркутск) |
|---|---|---|---|
| «Где / кто в городе» | 30 % | 9 | «Где в Иркутске поставить имплант?», «Посоветуй стоматологию в Октябрьском районе» |
| «Сколько стоит» | 20 % | 6 | «Сколько стоит имплант под ключ в Иркутске в 2026 году?» |
| «Как выбрать» | 20 % | 6 | «Как выбрать клинику для имплантации, на что смотреть?» |
| Сравнительные / «лучшие» | 20 % | 6 | «Какая стоматология в Иркутске лучше для имплантации: топ-5» |
| Проблемные / срочные | 10 % | 3 | «Болит зуб ночью, куда обратиться в Иркутске?» |
| **Брендовые** (отдельный блок) | — | 10 промптов | «Что известно о клинике X?», «X или Y — что выбрать?», «Сколько стоит имплант в X?» |

3. **Перефразы.** Для каждого интента пишу 2 формулировки разного стиля: короткую поисковую («имплант цена Иркутск») и разговорную («подскажи, где недорого и надёжно…»). Смысл не меняю. Шаблон «назови 5 компаний» — не больше чем в трети интентов, иначе доля упоминаний искусственно завышается.
4. **Брендовые промпты считаю отдельно.** Брендовый промпт почти всегда выдаёт упоминание, поэтому он измеряет точность фактов и тональность, а не видимость.

6. **Параметры прогона фиксирую и записываю:** модель и её версия, температура (по умолчанию провайдера, одинаковая для всех), регион и язык, системный промпт — пустой или нейтральный, одинаковый. Без «ты маркетолог».

## 2. Как считать интервал

### 2.1. Формула Уилсона

Для x упоминаний из n ответов, p̂ = x/n, z = 1,95996 (95 %):

- центр = (p̂ + z²/(2n)) / (1 + z²/n)
- полуширина = z · √( p̂(1 − p̂)/n + z²/(4n²) ) / (1 + z²/n)
- ДИ = [центр − полуширина; центр + полуширина]

Нормальное приближение «p̂ ± 1,96·√(p̂(1−p̂)/n)» (Вальд) не использую. При малых p̂ и n оно даёт отрицательные границы и слишком узкие интервалы.

### 2.2. Пример руками: 12 упоминаний из 90 [расчёт]

| Шаг | Вычисление | Результат |
|---|---|---|
| 1 | p̂ = 12/90 | 0,13333 |
| 2 | z² = 1,95996² | 3,84146 |
| 3 | z²/n = 3,84146/90 | 0,04268 |
| 4 | знаменатель 1 + z²/n | 1,04268 |
| 5 | z²/(2n) = 3,84146/180 | 0,02134 |
| 6 | центр = (0,13333 + 0,02134)/1,04268 | 0,14834 |
| 7 | p̂(1−p̂)/n = 0,13333·0,86667/90 | 0,001284 |
| 8 | z²/(4n²) = 3,84146/32 400 | 0,000119 |
| 9 | √(0,001284 + 0,000119) | 0,03745 |
| 10 | полуширина = 1,95996·0,03745/1,04268 | 0,07040 |
| 11 | ДИ = 0,14834 ± 0,07040 | **7,8 % – 21,9 %** |

Для сравнения: Вальд даёт 6,3–20,4 %.

**С поправкой на кластеризацию.** Если 90 ответов — это 45 промптов × 2 повтора и ICC = 0,5, то DEFF = 1,5. Тогда n_eff = 90/1,5 = 60, x_eff = 12/1,5 = 8, и ДИ Уилсона для 8/60 = **6,9–24,2 %**. Интервал расширился примерно на 4 п.п.

### 2.3. Оценка ICC по своим данным

Для каждой поверхности беру 0/1 «бренд упомянут» по k промптам с m повторами каждый и считаю однофакторный ANOVA:

- p̄ᵢ — доля по промпту i, p̄ — общая доля;
- MSB = m · Σᵢ (p̄ᵢ − p̄)² / (k − 1) — дисперсия **между** промптами;
- MSW = Σᵢ Σⱼ (yᵢⱼ − p̄ᵢ)² / (k·(m − 1)) — дисперсия **внутри** промптов;
- **ICC = (MSB − MSW) / (MSB + (m − 1)·MSW)**; отрицательное значение считаю равным 0;
- DEFF = 1 + (m − 1)·ICC, n_eff = n/DEFF.

Пример **[расчёт]**: 45 промптов × 2 повтора. В 4 промптах бренд упомянут оба раза, в 4 — один раз из двух, в 37 — ни разу (x = 12, n = 90). ICC = 0,62, DEFF = 1,62, Уилсон на n_eff — 6,7–24,7 %.

При 30–60 промптах сама оценка ICC шумная. Поэтому ICC использую как диагностику («повторы почти совпадают / почти случайны»), а интервал в отчёт даю по бутстрэпу.

### 2.4. Кластерный бутстрэп по промптам (основной способ)

Перевыбираю **промпты целиком** (все их повторы) с возвращением, 5 000 раз, и беру 2,5-й и 97,5-й перцентили доли. В том же примере бутстрэп даёт **5,6–23,3 %** **[расчёт]**. Когда есть перефразы, кластером делаю **интент** (все перефразы и повторы вместе). Это консервативнее и честнее.

```python
import random
from math import sqrt
from statistics import NormalDist, mean

Z = NormalDist().inv_cdf(0.975)

def wilson(x, n, z=Z):
    p = x / n
    c = (p + z*z/(2*n)) / (1 + z*z/n)
    h = z * sqrt(p*(1-p)/n + z*z/(4*n*n)) / (1 + z*z/n)
    return max(0, c - h), min(1, c + h)

def icc(clusters):              # clusters: {промпт: [0/1, 0/1, ...]} с равным m
    cl = list(clusters.values()); k, m = len(cl), len(cl[0])
    g = mean(v for c in cl for v in c)
    msb = m * sum((mean(c) - g)**2 for c in cl) / (k - 1)
    msw = sum((v - mean(c))**2 for c in cl for v in c) / (k * (m - 1))
    return (msb - msw) / (msb + (m - 1) * msw)

def boot_rate(clusters, B=5000, seed=1):
    rnd, cl = random.Random(seed), list(clusters.values())
    est = sorted(sum(map(sum, s)) / sum(map(len, s))
                 for s in ([rnd.choice(cl) for _ in cl] for _ in range(B)))
    return est[int(.025*B)], est[int(.975*B) - 1]

def boot_diff(a, b, B=5000, seed=1):
    """Парная разница долей (две системы или два бренда на ОДНИХ промптах)."""
    rnd, keys = random.Random(seed), list(a)
    est = []
    for _ in range(B):
        s = [rnd.choice(keys) for _ in keys]
        pa = sum(sum(a[k]) for k in s) / sum(len(a[k]) for k in s)
        pb = sum(sum(b[k]) for k in s) / sum(len(b[k]) for k in s)
        est.append(pa - pb)
    est.sort()
    return est[int(.025*B)], est[int(.975*B) - 1]

# пример: 45 промптов × 2 повтора; a — наш бренд, b — конкурент
a = {f"p{i}": v for i, v in enumerate([[1,1]]*4 + [[1,0]]*4 + [[0,0]]*37)}
b = {f"p{i}": v for i, v in enumerate([[1,1]]*10 + [[0,1]]*6 + [[0,0]]*29)}
x = sum(map(sum, a.values())); n = sum(map(len, a.values()))
r = icc(a); d = 1 + (2 - 1) * r
print(x, n, wilson(x, n), r, wilson(x/d, n/d), boot_rate(a), boot_diff(b, a))
# 12 90 (7.8%, 21.9%) 0.622 (6.7%, 24.7%) (5.6%, 23.3%) (+7.8, +24.4 п.п.)
```

## 3. Правила значимости

### 3.1. Какую разницу разрешено называть значимой

Правило: разницу называю «значимой» только если **95 % ДИ разности не содержит 0** (после поправки на кластеризацию и, если сравнений много, после поправки Холма). Одного правила «на глаз выглядит больше» недостаточно.

Ориентир — критическая наблюдаемая разница при |z| = 1,96 для двух независимых групп **[расчёт]**:

| n_eff на группу | p ≈ 10 % | p ≈ 15 % | p ≈ 30 % | p ≈ 50 % |
|---|---|---|---|---|
| 57 (19 900, пессимистично) | 11,0 п.п. | 13,1 | 16,8 | 18,4 |
| 80 (19 900, базово) | 9,3 | 11,1 | 14,2 | 15,5 |
| 114 (39 900, пессимистично) | 7,8 | 9,3 | 11,9 | 13,0 |
| 160 (39 900, базово) | 6,6 | 7,8 | 10,0 | 11,0 |

Практическое правило для отчёта:
- **19 900:** разницы меньше **~10 п.п.** (при долях около 10–15 %) и меньше **~15 п.п.** (при долях 30–50 %) не называю разницей ни при каком раскладе. Более крупные называю, только если прошёл тест.
- **39 900:** пороги соответственно **~7 п.п.** и **~11 п.п.**
- Критическая разница — не то же самое, что MDE. MDE (табл. 1) — эффект, который я **с вероятностью 80 %** замечу. Эффект размером с критическую разницу я замечу лишь в половине случаев.

### 3.2. Какой тест для какого сравнения

| Сравнение | Структура данных | Что использую |
|---|---|---|
| Бренд vs конкурент в одних и тех же ответах одной поверхности | Парные (один ответ → два признака) | Парный кластерный бутстрэп разности по промптам (`boot_diff`). Если повторов нет — тест Макнемара |
| Поверхность A vs поверхность B на одном наборе промптов | Парные по промпту | Парный кластерный бутстрэп разности |
| До / после (новый прогон тех же промптов через 7–14 дней и позже) | Парные по промпту, разное время | Парный кластерный бутстрэп по промптам; для грубой проверки — тест двух долей / Ньюкомб на n_eff |
| Разные наборы промптов (разные клиенты, города) | Независимые | Тест двух долей (z-тест) на n_eff или ДИ разности по Ньюкомбу |

**ДИ разности по Ньюкомбу** (метод 10, гибрид Уилсона). Беру ДИ Уилсона [l₁; u₁] для p̂₁ и [l₂; u₂] для p̂₂, d = p̂₁ − p̂₂:

- нижняя = d − √((p̂₁ − l₁)² + (u₂ − p̂₂)²)
- верхняя = d + √((u₁ − p̂₁)² + (p̂₂ − l₂)²)

При кластеризации подставляю x/DEFF и n/DEFF.

Примеры (45 промптов × 2, DEFF 1,5) **[расчёт]**:
- 12/90 → 27/90: без поправки p = 0,007; с DEFF p = 0,027, ДИ разности по Ньюкомбу от −30,7 до −1,9 п.п. → **значимо**, но ДИ широкий.
- 12/90 → 20/90: с DEFF p = 0,20, ДИ от −22,5 до +5,0 п.п. → **не значимо**.
- Бренд 12/90 vs конкурент 26/90 в тех же ответах: парный бутстрэп даёт разность +15,6 п.п., ДИ от +7,8 до +24,4 → **значимо**. Парный дизайн мощнее независимого.

### 3.3. «Интервалы не пересекаются» vs тест

- Если интервалы **не пересекаются**, разница значима. Но это правило слишком строгое: значимые разницы оно часто пропускает.
- Если интервалы **пересекаются**, это **не** значит, что разницы нет. Пример **[расчёт]**: 30/120 (ДИ 18,1–33,4 %) и 50/120 (ДИ 33,2–50,6 %) пересекаются, но тест двух долей даёт p = 0,006.
- Поэтому вывод о разнице делаю **только по ДИ разности или тесту**. Пересечение интервалов в отчёте не использую как аргумент ни в одну сторону.

### 3.4. Множественные сравнения

4 генеративные поверхности × (бренд + 7 конкурентов) — это десятки попарных сравнений. При α = 0,05 одно-два «значимых» различия получатся случайно.

- **Заранее** объявляю 3–5 главных сравнений (например, «бренд vs лидер на каждой поверхности»). Их считаю без поправки, если они заявлены до прогона.
- Все остальные — с **поправкой Холма**: сортирую p-значения по возрастанию p₍₁₎ ≤ … ≤ p₍ₘ₎, умножаю p₍ᵢ₎ на (m − i + 1), делаю последовательность неубывающей и сравниваю с 0,05. Пример **[расчёт]**: p = 0,004; 0,012; 0,03; 0,04; 0,2 → скорректированные 0,02; 0,048; 0,09; 0,09; 0,2. Значимы только первые два.
- Если поправку не делаю, пишу в отчёте: «сравнений N, часть различий может быть случайной; выводы — только по заранее заявленным сравнениям».

### 3.5. Ноль упоминаний

- Точечная оценка 0 % — это не «вас там нет». Это «доля, скорее всего, ниже X %».
- **Правило трёх:** верхняя 95 % граница ≈ 3/n_eff. Для n_eff = 80 это 3,8 % (точно: 1 − 0,05^(1/80) = 3,7 %). Уилсон даёт 4,6 %, в отчёте указываю его как более консервативный.
- В отчёте: «0 из 120 ответов (эффективно ~80 независимых). С 95 % уверенностью доля ниже ~5 %».
- Если 0 и у бренда, и у конкурента, сравнивать нечего: разница не определена.

### 4.2. Пример абзаца отчёта

- **Лимит Search API:** 1 генеративный запрос в секунду и 1 000 в час, поэтому прогон 39 900 (260 запросов) укладывается в один час.

## 7. Чек-лист методики (10 пунктов)

1. Промпты, перефразы, список конкурентов и правила кодирования «упоминания» зафиксированы **до** прогона и приложены к отчёту. Брендовые промпты считаются отдельно и в долю видимости не входят.
2. Небрендовых интентов не меньше 30 (19 900) / 60 (39 900), по 2 перефразы и 2 повтора. Повторы разнесены во времени не меньше чем на час.
3. Каждая поверхность подписана честно: модель, версия, режим поиска, дата. «Search API» не выдаётся за «Поиск с Алисой», а «OpenAI API» — за «ChatGPT».
4. Доля в выдаче Perplexity Search API считается и показывается **отдельно** от долей упоминаний в генеративных ответах.
5. Каждая доля — с n, числом промптов и 95 % ДИ: кластерный бутстрэп по интентам (основной) и Уилсон на n_eff (для проверки).
6. ICC или доля промптов, где повторы совпали, посчитана и показана. Если ICC > 0,5, это прямо сказано в отчёте.
7. Разница называется значимой только по ДИ разности или тесту (парный бутстрэп / Ньюкомб / тест двух долей), не по пересечению интервалов и не по порогу «на глаз». Разницы меньше критической (табл. в 3.1) — «в пределах разброса».
8. Главные сравнения объявлены заранее. Остальные — с поправкой Холма или с явной оговоркой о множественных сравнениях.
9. Ноль упоминаний описан верхней границей (Уилсон / правило трёх), а не словами «вас нет».
10. В тексте нет запрещённых фраз из раздела 5. Никаких гарантий, «позиций №1», процентов без интервала и средних по системам. Повторный замер интерпретируется с учётом MDE, без приписывания изменений работам.
