# Цифры пилота 25.09.2026: Алиса − ChatGPT — пересчёт с n и интервалами

**Дата: 25.09.2026.** Задача (решение владельца в PR): пересчитать разницы долей упоминаний «Поиск с Алисой» − ChatGPT по прогону 25.09.2026 с числом ответов n и интервалами Уилсона; где разница не значима — так и написать.

## Главное: фактический результат по сырым k/n
Сырые k/n из журнала прогона получены и проверены скриптом `metodika/tri_cifry.py`. Разница значима, только если 95 % интервал Ньюкомба для разности не содержит 0.

| компания | Алиса, k/n = доля [95 % Уилсон] | ChatGPT, k/n = доля [95 % Уилсон] | разность, п.п. [95 % Ньюкомб] | вердикт |
|---|---|---|---|---|
| Nomad Car Rental (nomadcar.kg, прокат авто, Бишкек) | 39/48 = 81,2 % [68,1; 89,8] | 29/96 = 30,2 % [21,9; 40,0] | +51,0 [+34,6; +62,9] | **значима** |
| Бобкэт Центр (bc-irkutsk.ru, аренда спецтехники, Иркутск) | 15/35 = 42,9 % [28,0; 59,1] | 19/72 = 26,4 % [17,6; 37,6] | +16,5 [−2,1; +35,0] | не значима |
| СпецЛидер (sl38.ru, аренда спецтехники, Иркутск) | 9/53 = 17,0 % [9,2; 29,2] | 16/108 = 14,8 % [9,3; 22,7] | +2,2 [−8,9; +15,6] | не значима |

С поправкой на повторы промптов (эффективный n = n / DEFF):
- Nomad Car: DEFF 2 — [+27,1; +66,6], DEFF 3 — [+21,2; +68,9]. **Остаётся значимой.**
- Бобкэт Центр: DEFF 2 — [−9,0; +41,6], DEFF 3 — [−13,9; +46,1]. Не значима.
- СпецЛидер: DEFF 2 — [−13,2; +21,7], DEFF 3 — [−16,4; +26,4]. Не значима.

**Итог.** Единственная доказанная цифра пилота — Nomad Car, +51 п.п. [+34,6; +62,9]: одна компания, одна дата, это пилотный кейс, а не закономерность. По Бобкэт Центру и СпецЛидеру разница в пределах погрешности.

Как считать заново: `python3 metodika/tri_cifry.py` без аргументов печатает эту таблицу (DEFF 1, 2, 3) и пороговую таблицу ниже; с аргументами `k1 n1 k2 n2 [deff]` — любой другой случай.

## Пороговая таблица (для +51 п.п.)
Составлена до получения сырых k/n: при каком n разница такого размера становится значимой. Разница считается значимой, если 95 % интервал Ньюкомба для разности долей не содержит 0 (правило из `metodika/audit-v2.md`; пересечение интервалов Уилсона как критерий не используется). n — ответов на **каждую** систему по этой компании. DEFF — поправка на повторы одного промпта (ICC ≈ 0,5, из `research-mehanika/05-metriki.md`).

| цифра | базовая доля у меньшей стороны | n (независимые) | n (2 повтора, DEFF 1,5) | n (3 повтора, DEFF 2,0) |
|---|---|---|---|---|
| +51 п.п. (прокат авто) | 5% → 56% | 7 | 10 | 13 |
| +51 п.п. (прокат авто) | 20% → 71% | 8 | 11 | 15 |
| +51 п.п. (прокат авто) | 30% → 81% | 7 | 11 | 14 |

Фактические n (48 и 96) с запасом выше порога — это совпадает с результатом пересчёта.

## Две поправки, которые ухудшают картину
1. **Множественные сравнения.** +51 п.п. — самая крупная разница из сравнений по нескольким компаниям. Самая крупная из многих случайных разниц всегда выглядит внушительно. При поправке Холма на 7 сравнений самая сильная разница проверяется на уровне 0,05/7 ≈ 0,007 — пороги n для неё растут примерно в 1,5–1,7 раза. Для +51 при фактических n это не критично.
2. **Одна дата.** Даже значимая разница описывает один день. Устойчивость проверяется повторным прогоном по тому же протоколу (A/A-тест, `metodika/chistaya-sessiya.md`).

## Пример работы скрипта (цифры условные, не из прогона)
```
$ python3 metodika/tri_cifry.py 13 30 5 30 1.5
Алиса: 13/30 = 43.3%  [95 % Уилсон: 27.4% – 60.8%]
ChatGPT: 5/30 = 16.7%  [95 % Уилсон: 7.3% – 33.6%]
Разность: +26.7 п.п.  [Ньюкомб, DEFF=1.5: -1.7 … +50.2]
НЕ ЗНАЧИМА: интервал разности содержит 0
```
Разница +26,7 п.п. при 30 ответах на систему с повторами промптов — **не значима**. Так выглядит типичная «эффектная» цифра на малой выборке.

## Как пересчитать по-настоящему (15 минут)
1. Из журнала прогона (`runs.jsonl` или таблица) выписать по каждой компании: n ответов Алисы, k упоминаний у Алисы, n и k у ChatGPT, число повторов на промпт.
2. Запустить `python3 metodika/tri_cifry.py k_алиса n_алиса k_chatgpt n_chatgpt DEFF` (DEFF = 1 без повторов, 1,5 при двух, 2,0 при трёх).
3. В оффер и лендинг переносить только значимые разницы, с интервалом и n. Незначимые — формулировкой «разница в пределах погрешности».
